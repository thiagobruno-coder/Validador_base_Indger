Opções avançadas
O site da ANEEL usa uma verificação de segurança (Cloudflare) que costuma recusar navegadores abertos automaticamente; se a verificação ficar repetindo, use a opção "pelo meu Chrome".
  1. Só na primeira vez: arraste este botão para a barra de favoritos do Chrome (se a barra não aparecer, aperte Ctrl+Shift+B):
    📥 Coletar ANEEL
  2. Escolha o período e as listas acima e clique em "Abrir site da ANEEL" (botão abaixo).
  3. No site, passe pela verificação normalmente. Quando a lista de reuniões aparecer, clique no favorito 📥 Coletar ANEEL.
  4. Uma caixa aparece no canto do site mostrando o progresso, e o andamento também aparece aqui. Deixe a aba do site aberta até terminar.

Se o Chrome perguntar se o site pode acessar dispositivos da rede local, clique em Permitir: é o site conversando com este painel no seu computador.
